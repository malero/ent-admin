# Vendored VSN runtime

`vsn.min.js` is the minified VSN browser runtime used by the phase-one
progressive preview interaction.

- Package: VSN `1.0.15`
- Source: https://github.com/malero/vsn
- Source revision: `32c7e21`
- Upstream license: MIT (declared by the VSN package)
- SHA-256: `7e5be5cfb72820bcd683788b2cae969de930b4bf5022f09a987c5d1deb473d2b`

The file is served under the configured Ent Admin base path, so the example
does not require a CDN or another external service at runtime.
